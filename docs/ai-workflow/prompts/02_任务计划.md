# Task Plan Prompt

```text
你现在只为任务 `{TASK_ID} {TASK_NAME}` 编写实施计划，不得修改业务代码或测试代码。

必须读取：

- 01_技术规格/记忆系统设计文档_全链路MVP技术选型版(9).md
- 02_开发管理/master_plan.md
- 02_开发管理/progress.md
- 02_开发管理/tasks/TASK_PLAN_TEMPLATE.md
- 当前仓库相关代码和测试

开始前检查：

1. 当前分支；
2. git status；
3. 最近 10 条 Git Commit；
4. 当前目录结构；
5. 对应规格章节；
6. 前置任务是否 completed；
7. 当前代码是否与规格一致。

创建：

`02_开发管理/tasks/{TASK_ID}-{TASK_SLUG}.md`

必须完整填写模板中的：

- 任务信息；
- 目标；
- 非目标；
- 当前代码状态；
- 分步骤实现方案；
- 文件变更清单；
- 原子性、幂等、并发、版本冲突、用户隔离、部分失败、进程恢复分析；
- Unit、Contract、Integration、E2E、失败注入和并发测试计划；
- 可客观验证的验收标准；
- 风险和阻塞项；
- Git 计划。

同时更新 progress.md：

- current_task；
- current_task_status=planned；
- current_branch；
- current_plan_file；
- next_action=计划审查。

完成后停止。

禁止：

- 修改业务代码；
- 修改测试代码；
- 安装依赖；
- 修改 Migration；
- 执行 Commit；
- 自行解决会改变规格的冲突。
```
