# Bug Fix Prompt

```text
请修复以下 Bug：

{BUG_DESCRIPTION}

要求：

1. 先复现；
2. 找到对应规格章节；
3. 判断是实现错误、测试错误、配置错误还是规格冲突；
4. 编写当前会失败的回归测试；
5. 只修改根因；
6. 不做无关重构；
7. 检查影响：
   - 幂等；
   - 并发；
   - 用户隔离；
   - 数据一致性；
   - 错误语义；
   - 恢复流程；
8. 修复后运行：
   - 回归测试；
   - 所属模块测试；
   - 受影响 Integration/E2E；
   - Ruff；
   - Mypy；
9. 更新当前 Task Plan；若当前 Task 已完成，创建独立 Bug Plan；
10. 推荐独立 Fix Commit；
11. 不执行 Push。
```
