# Test Completion Prompt

```text
请针对任务 `{TASK_ID}` 独立检查并补全测试。

依据：

- 技术规格版（9）；
- 当前 Task Plan；
- 当前 Git Diff；
- 05_测试与验收/test_matrix.md。

不要修改业务规格，不得为了测试通过降低校验要求。

步骤：

1. 列出已有测试；
2. 将规格要求映射到测试场景；
3. 列出缺失测试；
4. 补全测试；
5. 优先编写能够发现真实错误的断言；
6. 使用 Fake Server 测试外部 LLM 和 Embedding 异常；
7. 真实基础设施语义使用 Integration Test；
8. 跨模块链路使用 E2E；
9. 覆盖：
   - 正常路径；
   - 输入边界；
   - 幂等；
   - 并发；
   - 用户隔离；
   - 版本冲突；
   - 外部依赖失败；
   - 部分成功；
   - 进程异常退出；
   - 人工恢复；
   - 日志与错误码；
10. 不允许 skip、xfail 或删除断言来隐藏失败，除非技术规格明确允许，并必须写明原因；
11. 运行相关测试、Ruff、Mypy；
12. 更新 Task Plan 测试结果和 progress.md；
13. 不执行 Commit。
```
